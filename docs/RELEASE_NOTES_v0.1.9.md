ReDox v0.1.9 improves the Windows 98 interface and sidebar layout.

- Classic scrollbars use square arrow buttons, beveled gray thumbs, and a dithered track. Arrow buttons repeat when held; thumb dragging and mouse-wheel scrolling remain available.
- The top bar uses a compact blue gradient caption, pixel-drawn window controls, and a tighter gray menu row.
- Codex history and Projects have separate scroll areas with matching borders and gray headers above their white lists.
- Archived projects appears below Projects. Long names truncate with full paths on hover, and Restore stays within the row.
- Expanded archive rows have a fixed height. The archive list scrolls within a 120-point limit, and its surrounding panel is capped to prevent it consuming the sidebar.

Download ReDox-Windows-x64.exe, or use Settings > Updates > Update and restart from an earlier release. Chats and settings are retained.

Validation: formatting, the full automated test suite, and an optimized Windows build. Includes regression checks for scrollbar interactions, archive row width and height, and a list of 100 archived projects. Visual appearance in the running app has not been verified.
